One line of weather forecast (130 characters) for Fogsworth, a city that does not exist: fog till eight, then clear skies — and the 7:40 train waits two extra minutes, because the conductor overslept too.

## Run it

```sh
python3 main.py
```

This writes the forecast line to `/output/entry.txt`.
